TomcatCon Training: Tomcat for Administrators

When

Tuesday, 10 April 2018

Where

Hotel Novotel Manchester Centre | 21 Dickinson Street | M1 4LX Manchester | United Kingdom

What

This training course is aimed at system administrators who are not very familiar with Apache Tomcat. It will provide them with the skills necessary to set up a Tomcat instance, administer it on a day to day basis and to undertake initial troubleshooting if things go wrong.

This course will be taught by Mark Thomas, a Tomcat committer and PMC member with over 15 years experience with Apache Tomcat.

Registration for this training course is now open.

Schedule

  • 09.00 Welcome
    Introductions and Welcome
  • 09.30 Installation
    Typical installation scenarios using packages from the ASF as well as popular distributions.
  • 10.30 Web Application Packaging and Deployment
    The options for deploying applications and an in-depth look at automatic deployment.
  • 11.30 Logging
    The default logging configuration and options for tailoring it for your production environment.
  • 12.30 Buffet Lunch
  • 13.30 TLS
    An introduction to TLS and how it works.
  • 14.30 TLS configuration
    Configuring Tomcat for TLS.
  • 15.30 Performance and tuning
    How to identify the source of bottlenecks in an application and options for addressing them.
  • 16.30 Wrap-Up
    An opportunity to ask any final questions

See you there!
