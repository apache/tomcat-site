Overview

Apache Tomcat project uses several automated build services provided by Apache Software Foundation. In short, those are:

  • Apache Gump
  • Buildbot
  • Jenkins

Apache Gump is used to test integration of Tomcat with latest versions of libraries it depends on. It also runs the automated tests. Buildbot and Jenkins are used to perform the usual nighty builds. The Buildbot also builds and publishes documentation snapshots for the currently developed not yet released versions of Tomcat.
