Verify the Integrity of the Files

You must verify the integrity of the downloaded files. We provide OpenPGP signatures for every release file. This signature should be matched against the KEYS file which contains the OpenPGP keys of Tomcat's Release Managers. We also provide MD5 and SHA1 checksums for every release file. After you download the file, you should calculate a checksum for your download, and make sure it is the same as ours.
