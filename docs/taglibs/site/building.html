Prerequisites

To build Jakara Taglibs packages you need to install Maven 2.

Building

The following applies to trunk and any releases containing a pom.xml. If the release contains a build.xml, refer to the Legacy Building page.

Until we release the Parent POM, you will first need to svn checkout the taglibs-parent:

svn co https://svn.apache.org/repos/asf/jakarta/taglibs/proper/taglibs-parent/trunk taglibs-parent

Then you should execute mvn clean install. Once you have done this you are ready to build the taglib.

Obtain your taglib, either from a source download or from svn. To build a taglib, execute mvn clean package.

Building the site

The main site is built by checking out the site/ directory: 

svn co http://svn.apache.org/repos/asf/jakarta/taglibs/proper/site site

Taglib specific sites are built by directly from that taglib.

To build either - execute mvn clean site.

Releasing

To build the tar.gz or .zip for a Taglibs release, execute mvn clean assembly:assembly.
